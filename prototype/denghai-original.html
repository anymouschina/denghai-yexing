操作

  • WASD / 方向键 移动；武器按冷却自动朝最近妖物攻击
  • 空格 / Shift 冲刺：短距离突进，0.25 秒无敌，冷却 2.5 秒
  • 升级三选一：鼠标点击或 1 / 2 / 3；每局 2 次「换一批」
  • Esc 暂停（继续 / 重开 / 回标题，并显示当前构筑）

核心循环（30 秒内在做什么）

走位躲妖物与弹幕 → 自动攻击清怪 → 拾取掉落的魂晶（经验）、铜钱、回血灯油 → 经验满暂停三选一构筑 → 妖物更多更强 → 再走位……
一局结束拿魂火，回标题在「灯坊」买永久强化，再来一局。

构筑：15 个升级 · 3 个流派 · 3 种进化

流派武器（自动攻击）流派被动进化（武器满 5 级 + 对应被动）
符箓 · 弹幕穿透驱邪符：朝最近敌人飞符，命中穿透疾书（冷却）、重符（弹体 +1）驱邪符 + 疾书 → 万符朝宗：环形齐射 + 符印二次爆
灯火 · 环绕灼烧灯火环：灯火绕身旋转灼魂（灼烧持续伤害）、添油（范围 +）灯火环 + 灼魂 → 长明灯阵：灯火常驻且留下火路
雷法 · 连锁暴击掌心雷：落雷并连锁跳跃雷引（连锁 +）、天罡（暴击率/暴伤）掌心雷 + 天罡 → 五雷正法：五道天雷 + 必暴击
通用草履（移速）、护身玉（最大生命）、魂袋（拾取范围）、桃木心（全伤害）、静心（冲刺冷却）、铜钱串（魂火获取）

流派联动：灼烧中的敌人受雷伤 +30%；符印被灯火触碰会提前引爆。卡片写具体数值与当前等级；稀有度白/蓝/紫/金。

难度曲线

  • 妖物血量每分钟 ×1.25，刷新间隔每分钟 ×0.9，同屏上限 220
  • 升级所需经验：5, 10, 15… 之后每级 ×1.15
  • 目标手感：第 1 分钟轻松 → 第 3 分钟紧张 → 构筑成形后割草 → Boss 前后有压力
  • 新手首局约撑 4–5 分钟；站着不动约 70 秒会被打倒

局外成长「灯坊」（存本地）

  • 命灯（最大生命 +10/级）· 桃木（伤害 +5%/级）· 草履（移速 +4%/级）
  • 魂袋（拾取范围 +15%/级）· 签筒（换一批 +1）· 还魂符（复活一次）
  • 价格逐级递增；死亡也给魂火，胜利额外 +50%
  • 里程碑解锁：首次撑过 4 分钟 → 「掌心雷」进入升级池

一局时长 & 手感承诺

一局 8 分钟（死亡更早结束）。打磨清单逐条做：受击白闪 + 击退 + 伤害飘字、暴击顿帧 60ms、小幅震屏、死亡纸屑/火星粒子、魂晶磁吸、受伤 0.8 秒无敌闪烁、UI 面板缓动与按钮回弹、ZzFX 音效 + 生成的战斗 BGM（可静音并记住设置）。

画风

2D 手绘卡通游戏素材，粗黑描边，两阶赛璐璐阴影，东方志怪 × 暗夜灯笼，俯视 3/4 视角，Q 版约 1:2.5 头身。角色明亮、场景偏暗：主角与掉落物永远是画面里最亮的东西，保证在妖物堆里一眼可见。夜色用一层径向暗角压低四周，主角灯笼照亮一圈。
