# 《灯骸夜行》v1.5 设计文档（Godot 迁移版）

> 玩法、规则与数值由设计拍板（不回头问用户）。沿用 H5 版的美术与数值表（`godot/data/*.json` 由 `src/data/*.json` 复制而来），v1.5 在其上新增「灯骸裂隙」副本、灯芯、游商、法宝飞剑术、3 段场地。
> 规则以 `godot/src/sim/sim.gd` 为唯一实现：游戏渲染层与 headless 平衡脚本共用同一份规则。

## 1. 三层循环

| 层 | 内容 | 时长 |
|---|---|---|
| 秒级（操作） | 走位躲妖物 / 弹幕 / 预警圈；拾取魂晶；冲刺（0.26s 无敌）；拿到飞剑术后「出鞘 → 回旋 → 召回刺出」 | 0–30s |
| 分钟级（构筑） | 经验满暂停三选一（武器 / 被动 / 进化）；精英掉宝箱（+2 级）；每段结束的「启程馈赠」三选一 | 30s–3min |
| 一局（决策） | 3 段场地 → 每个段间做取舍：**去游商换遗物 / 进裂隙拿法宝 / 直接领馈赠启程** → BOSS 灯骸老祖。一局约 8 分钟战斗 + 段间 | 8–10min |
| 局外 | 魂火 → 灯坊永久强化（命灯 / 桃木 / 草履 / 魂袋 / 签筒 / 还魂符） | 跨局 |

## 2. 3 个爽点

1. **割草 + 进化**：满级武器 + 对应被动 → 万符朝宗 / 长明灯阵 / 五雷正法（金色必出，换一批也刷不掉）。
2. **险中求胜的副本**：站定进入裂隙，限时单挑一个会跳、会震、会喷鬼火的守关者，赢了拿到「飞剑术」，输了只是掉 30% 血，不结束本局。
3. **飞剑术的动作维度**：出鞘回旋清场、叠 5 层剑痕，再抓准时机召回，向面朝方向刺出 1.8 倍二段——“放出去、收回来”有节奏，不是纯数值加成。

## 3. v1.5 规格（实现位置：`godot/src/sim/sim.gd`）

### 3.1 一局结构

```
S1 荒园灯市 0–160s ─段间1─ S2 荒坟夜雾 160–320s ─段间2─ S3 焦灯市 320–480s ─段间3(BOSS 前)─ 灯骸老祖
```

* 战斗时钟只在 S1/S2/S3/BOSS 里走；段间与裂隙里不走（妖物成长按战斗时钟）。
* 段间：妖物散去（精英留宝箱）、掉落全部吸向主角；场地中央出现「灯骸裂隙」，左侧游商，右侧「启程」。**站定 1 秒触发**（避免路过误触），40 秒无操作自动启程。
* 「启程」：领取该段段间的三选一馈赠后进入下一段。进裂隙即放弃这一次馈赠。
* 段间不回血（骨灯在段间不生效，馈赠池不出“回血”卡）。

### 3.2 灯芯（双用途闸门）

| 来源 | 数量 |
|---|---|
| 开局 | 2 |
| 第 3 段间（BOSS 前） | +1 |

用途：进裂隙 1 枚 / 游商换遗物 1 枚。总量 3 枚，进满 2 次副本后只剩 1 枚换遗物——不进副本的玩家能换到 3 件遗物。**这是防“每局必刷副本”的闸门**。

### 3.3 灯骸裂隙（副本）

| 项 | 规则 |
|---|---|
| 入口条件 | 段间；灯芯 ≥ 1；当前生命 ≥ 最大生命 60%（否则显示“灯弱，不可入”）；本局入过 < 2 次；该段间的裂隙未被封闭 |
| 进入 | 消耗 1 枚灯芯；放弃该段间三选一；掉落清空；玩家到场地中央（圆形场地半径 470） |
| 守关者 | 现有行为原型「跳尸王」（hop + 震击）+ 3 词缀 + 1.3 倍体型；复用现有怪物逻辑，不新写 AI 框架 |
| 词缀 | 迅捷（移速 +25%）/ 震地（震击冷却 ×0.7、范围 ×1.15）/ 灯焰（每 6.5s 0.5s 预警后喷 12 颗鬼火环） |
| 血量 | **= 玩家当前 DPS × 目标击杀秒数**（`Sim.build_dps()`：按武器单体有效输出 × 暴击期望 × 加算乘区，含飞剑估算）；护甲 20%（飞剑穿甲） |
| 时限 | 第 1 次：目标 55s、限时 70s；第 2 次：目标 70s、限时 90s |
| 副本内约束 | 无补给（油瓶不回血）、无三选一（升级排队）、骨灯全熄、冲刺冷却 ×1.25、受击硬直 ×1.2、守关者不掉经验 |
| 成功 | 第 1 次通关：**法宝《飞剑术》**；第 2 次通关：法宝已有（一局最多 1 件）→ 改发宝箱 |
| 失败 | 超时或在副本内致死：弹出、扣当前生命 30%（致死则按进入致死前的生命扣，至少 1 点）、灯芯不退、该段间裂隙封闭、**不结束本局** |
| 代价 | 出副本后（无论成败）**下一段威胁预算 +1 档**：刷怪间隔 ×0.88、妖物血量 ×1.10；BOSS 档则 BOSS 血量 ×1.06、多召唤 2 只纸扎人 |

### 3.4 法宝《飞剑术》

操作：键盘 `E` / `J` / 鼠标右键；触屏右下「剑」键。

| 状态 | 行为 |
|---|---|
| 收鞘 | 按键 → 出鞘 |
| 回旋 | 绕玩家椭圆（rx165 / ry100）旋转 6s，穿甲，每个妖物每 0.32s 受一次伤（20 点 × 加算乘区），每次命中叠 1 层剑痕 |
| 召回 | 再按键 → 0.3s 收束，随后向**面朝方向**（最后移动方向）刺出：长 430、半宽 44、穿透，伤害 = 单发 × **1.8**，同样叠剑痕 |
| 坠地 | 召回的 0.3s 内玩家受击 → 飞剑坠地 3 秒（不可用）；回旋期间受击不会坠地 |
| 冷却 | 刺出或超时归鞘后 2.5s |
| 剑痕 | 每层 +6% 承伤，5 层封顶，5 秒不续则清零 |

**加算不取乘乘**：伤害乘区 `1 + 局外 + 桃木心 + 遗物 + 武器进化(+15%，仅进化武器) + 目标剑痕层数×6%`，各项相加而不是相乘（`Sim._dmg_mul`）。

### 3.5 遗物（游商，6 件，每件 1 灯芯）

护身铜镜（受伤 −8%）/ 引魂铃（拾取范围 +35%）/ 铜钱剑穗（暴击 +8%）/ 灯罩（最大生命 +20）/ 纸马（移速 +8%）/ 破阵符（伤害 +8%，加算）。均为简单增益，不引入新系统。

## 4. 成长与难度曲线

* 升级经验：5/10/15/20/25，之后 ×1.15 每级；一局约 30–35 级。
* 妖物血量：`hpMulPerMin^分钟 × late^(超出 late.from 的分钟)`，late 段让后半局更陡（见 `data/waves.json`）。
* 刷怪：间隔 `1.2 × 0.76^分钟`（下限 0.22s），每次批量 `1 + 分钟×0.85 + late 分钟×…`；同屏上限见 waves.json（低端触屏机降到 150）。
* 触屏手感校准（只在触屏设备生效）：受伤 ×0.72、受击无敌 +0.35s、移速 ×1.07、冲刺冷却 ×0.85、拾取 ×1.2、刷怪间隔 ×1.15。**平衡数据按键鼠口径**。

## 6. 决策记录

| 决策 | 理由 |
|---|---|
| 规则放进纯数据的 `Sim`，渲染只读它 | 平衡脚本测的就是玩的那份规则；headless 下不需要节点，单局 ~2s |
| 站定 1 秒触发入口（而不是碰到就触发） | 路过误触会白白吃掉灯芯；同时对手机摇杆更友好 |
| 灯芯总量 3、进满副本只剩 1 | 让“不进副本”成为有竞争力的路线（3 件遗物），而不是必刷 |
| 失败也让威胁 +1 档 | 副本是有代价的赌注，不是只有奖励的白嫖 |
| 守关者血量按 DPS 生成而非表 | 副本难度跟玩家构筑同步，不会因为构筑强弱变成“秒杀”或“不可能” |
| 飞剑做动作维度而非纯数值 | 用户明确口味：法宝是“多一个动作”，不是 +x% |
| 触屏手感校准保留、平衡按键鼠口径 | 手机摇杆比键鼠粗，难度校准保持体验；数据口径一致才有可比性 |
| BGM 复用 H5 的程序化编曲（录制成 mp3 循环） | 平台没有音乐生成模型；不重新作曲，保持原作听感 |
