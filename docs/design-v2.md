# 《灯骸夜行》v2 设计文档（Godot 版）

状态标记：【已实现】= 代码里有且自检覆盖；【已测】= 有实测数据；【设计】= 本稿给出规格，尚未实现。

## 1. 现状实测（回答“关卡现在能玩到多久”）【已测】
`godot/tests/timeline.gd`，真人代理整局（单局 ≈3 秒仿真）：
| 项 | 数值 |
|---|---|
| 战斗时钟 | S1 0–160s → 段间 → S2 160–320s → 段间 → S3 320–480s → 段间 → BOSS（480s 登场） |
| 整局墙钟（不进副本，通关） | ≈ 500–570s（约 8.5–9.5 分钟），BOSS 击杀 22–60s |
| 进 2 次副本 | 墙钟 ≈ 650–710s（每次副本 ≈ 70–90s + 段间 ≈ 3–70s） |
| 段数/层数 | 3 段场地 + 1 个 BOSS；无“层” |
| 地图 | 2500×1394，可走区 2160×1054 ≈ 2.28M px²，约为视口(1280×720)的 3.8 倍 |
| 玩家能玩到的上限 | 通关即 BOSS 死（≈9 分钟）；死亡则更早（样本里 4:57–8:06） |
**结论**：现版本一局 ≈ 8–10 分钟，远低于用户设定的 30 分钟；地图也偏小。v2 目标：默认 30 分钟、地图 3600×2400。

## 2. 性能诊断【已测】
基线（`tools/bench.mjs`，Chrome+Metal，CPU 降速 4× 模拟中低端手机）：同屏 300 只 40.8 FPS / p99 49.9ms / >33ms 帧 6.8%；500 只 29.4 FPS / 33%。本机无降速 300 只即 60 FPS。
分项（300 只、4×）：`world_draw` 10.7ms（妖物 4.7、掉落 1.6、阴影 0.9）、`sim_step` 3.2、HUD 0.5。主因（按占比）：
1. 世界绘制逐实体提交且“阴影/精灵/线条”交替打断合批（draw_calls 1142）；
2. 屏外实体也提交；
3. 每帧 `sort_custom` 闭包 + 每实体数组/字典分配；
4. 5 种小怪 5 张贴图、4 张大背景 JPG 常驻（tex_mb 76MB，其中背景 ≈ 43MB）。

## 3. 优化清单与结果【已实现/已测】
| 项 | 改法 | 结果 |
|---|---|---|
| 视口裁剪 | `_visible()` | 屏外实体不提交 |
| 排序 | `PackedInt64Array.sort()` | 去闭包与分配 |
| 阴影/掉落分批 | 单独一遍，同贴图连续 | draw_calls 1142→528 |
| 小怪图集 | `enemy_atlas.png` + `data/enemy_atlas.json`，仍按 `anchors.json` 中轴镜像（朝左修复不变） | 5 张贴图→1 张 |
| 叠加循环 | 血条/剑痕/符印移出 `_draw_enemy` | 贴图与线条不再混排 |
| 去分配 | `_enemy_cache` 常量表；`PICKUP_TEX` 常量 | 逐帧分配归零 |
| 背景 | 4 张压到 1280×720，按段/秘境按需加载，镜像无缝平铺 | tex_mb 76.2→36.6，包 52→47MB |
结果见 `PERF.md`：4× 降速 300 只 **60 FPS、p99 16.8ms、>33ms 0%**；500 只 48.8 FPS、>33ms 2.2%；draw_calls 296（未达 <120），tex_mb 36.6（未达 <30），包体 47MB（wasm 39.5MB 为官方模板，不可再压）。

## 4. 飞剑 5 阶 + 剑灵 + 融合【已实现】
- 主干 5 阶累加：1 回旋/召回刺出；2 双剑交替（刺出后反向再刺）；3 环身剑轮；4 追踪剑气（锁最近目标、穿透）；5 剑阵爆发（多剑、必暴击）。
- 晋升：击杀“剑意” 300/1000/2400/4800，或击败副本守关者（确定性 +1 阶）；每次晋升三选一分叉（剑数+1 / 回旋扩阔 / 剑意疾速，各 3 级）。
- 副本守关者「剑灵」专属机制：御剑环身（灵剑绕身，可被飞剑回旋击落）/ 回鞘突刺（冲完露破绽 承伤×1.35）/ 剑雨。
- 融合：局内 5:30 起必现（符剑/灯剑/雷剑合璧），缺飞剑则剑冢遗赠。参数 `data/dungeon.json`。

## 5. 遗物 / 铜钱商店 / 进化配件 / 套装【设计】
**铜钱阶梯**：白 50 / 蓝 110 / 紫 200 / 金（进化配件，需对应武器或被动满级）340。词条强度随价格带单调递增，禁止“便宜且强”。灯芯保留用于进裂隙/刷新商店。
**4 把进化配件**：驱邪符→镇魂连爆符（命中符印连锁爆）；灯火环→冥火聚魂灯（灯火吸附聚怪）；掌心雷→引雷铜柱（落雷留柱持续放电）；飞剑→玄铁剑匣·双影（剑轮多一圈影剑）。
**8 组套装**（2–3 件激活）：
| 套装 | 材料 | 效果 | 强度闸门 |
|---|---|---|---|
| 暴击金光 | 铜钱剑穗+破阵符 | 暴击溅射 40% | 紫 |
| 回血汲灯 | 引魂铃+灯罩 | 拾取回血、冲刺 CD-10% | 蓝 |
| 反震 | 护身铜镜+灯罩 | 受击清近弹幕 | 蓝 |
| 灼烧传染 | 灯火环满级+纸马 | 灼烧死亡扩散 | 紫 |
| 雷火超载 | 掌心雷+灯火环满级 | 落雷点燃 | 紫 |
| 疾行剑气 | 纸马+飞剑 3 阶 | 冲刺留剑气 | 紫 |
| 聚财招魂 | 引魂铃+铜钱串 | 铜钱磁吸/魂火+ | 白 |
| 镇煞护心 | 护身铜镜+护身玉 | 低血量减伤 | 蓝 |
**30 分钟经济**：铜钱产出 ≈ 25–35 枚/分钟（掉率 4%+精英/宝箱），全局约 800–1000 枚：可买约 3 件紫+若干白蓝，凑齐 1 件金进化配件需要收集+取舍。

## 6. 彩虹葫芦 / 葫芦小金刚【设计】
七色散件（赤火伤/橙暴击/黄减伤/绿喷火/青减速/蓝闪避/紫吸怪），来源：灵藤探索点、古药葫芦秘境、精英/BOSS、游商；**只掉未拥有颜色**。集齐合成宠物：环绕寻敌喷火/落雷/冲击波，DPS 上限 ≈ 1 件满级武器（占队伍 DPS ≤ 25% 作为闸门）；主动“七彩合击”（Q/触屏“葫”键，冷却 40s）；独立 HP/护盾；阵亡后 45s 复活冷却 + 掉 1 层强化印记，击杀精英/拾魂晶可恢复。成长曲线：散件数 1–6 逐步给词条，7 片合成宠物。

## 7. 地图与探索【设计】
3600×2400 镜像无缝平铺，4 象限地标（北古井祭坛/东破败牌坊/西灯冢废墟/南荒庙香炉）；出生点 350px 内必刷 1 处古灯宝箱或灵藤；右上小地图 + 屏边箭头；3 类秘境（剑冢裂隙→剑灵+飞剑升阶；古药葫芦秘境→必得 1 片散件；镇魂宝库→高风险精英潮，铜钱 220–360+进化件）。探索度指标：一局可发现点 ≥ 15、可选决策 ≥ 8 次、秘境 ≥ 5 个。

| 5:00 | 跳尸王 | 2:00 精英 |
| 5:30 | 飞剑×武器融合（两模式一致） | 6:30（旧）/5:30（现） |
| 10:00 | 破灯笼王 | 6:00 精英 |
| 15:00 / 20:00 / 25:00 | 剑冢真主 / 纸轿冥娘 / 百灯鬼王 | — |
