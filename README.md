# 《灯骸夜行》v2.0 · Godot 版

暗夜灯笼国风 · 俯视角割草肉鸽。运行本体是 Godot 4.7.2（`godot/`），发布形态是 Web/HTML5 导出（`build/web/`），Android 导出预设已配（本轮未出包）。H5（Phaser）旧版原样保留在仓库根目录（`src/` `public/` `index.html`）。历史迭代记录（v1.5–v1.7 的逐轮说明）归档在 `docs/history-README-v1.5-v1.7.md`，其中的「未做/未收敛」是当时状态，以本页和下面三份报告为准。

## 怎么跑
```bash
G=~/TapCanvasAgent/.tools/godot/current/Godot.app/Contents/MacOS/Godot
$G --headless --path godot --script tests/selftest.gd        # 规则自检（199 项，0 失败）
python3 tools/run_balance.py --bot proxy --tier 0 --n 300 --procs 10   # 平衡（tier 0/1/2 = 不进/进1/进2 次剑冢）
tools/export_web.sh                                           # 导出 build/web
THROTTLE=4 node tools/bench.mjs 300,500 out.json 12 1         # 性能压测
node tools/e2e_facing.mjs                                     # 朝左/失焦防卡键回归
```
键位：WASD/方向键移动、空格冲刺、E/J 飞剑、Q/R 葫芦合击（触屏「葫」键）、1/2/3 选卡、Esc 暂停（暂停里 X 或按钮=结算本局）。标题页 Enter/点空白=**新开一局**，「继续本局」是单独按钮；存档在 localStorage 键 `denghai_yexing_save_v15`（同写 `user://save.json`），「清空存档」在标题页。手感参数在 `godot/data/movement.json`。

## 玩法（v2.0）
- 地图 3600×2400，小地图、探索足迹、4 象限地标；POI：2 处剑冢裂隙（战剑灵，通关飞剑 +1 阶）、游商灯摊、2 处葫芦灵藤、古药葫芦秘境、镇魂宝库。
- 模式：完整夜行 30 分钟（6 段主题 + 每 5 分钟阶梯小 BOSS：跳尸王/破灯笼王/剑冢真主/纸轿冥娘/百灯鬼王，灯骸老祖压轴）/ 疾速试炼 10 分钟；融合按真实战斗时钟 5:30 必现。
- 飞剑 5 阶累加（回旋刺出→双剑→剑轮→追踪剑气→剑阵）；铜钱商店（白50/蓝110/紫200/金340）、16 件遗物、8 组套装（含机制效果）、4 把满级进化配件；7 色葫芦→葫芦小金刚（Q 合击、45s 复活冷却、掉印记）。
- 副本剑灵专属机制（御剑环身/回鞘突刺/剑雨）。

## v2.1 打磨（2026-11-19，完整/疾速模式；经典口径不动，作平衡基线）
- **七彩葫芦一定能集齐**：保底按模式配置（`gourds.json → guarantee`）：完整每 170 秒、疾速每 80 秒保底一件，7×80=560 秒＜10 分钟。以前疾速只能靠保底拿到 3 件，实测终局前只有 6 件。来源：灵藤、守关 BOSS 必掉、葫芦藤秘境、游商直购、牌坊许愿、保底；巡场妖王改在每段中段出场（`fullMid`/`quickMid`），不再与段末守关撞车。
- **练级点（可反复刷）**：大地图新增「聚宝鬼市」（每只妖物必掉铜钱，按节奏钟涨价）和「炼魂坑」（魂火 ×3，通关直升 1 级）。站定进入，坚持 45 秒，冷却 60 秒。在里面花的是大地图时间（时钟照走），所以刷是拿时间换资源，一局不会被无限拉长。进副本类场地时大地图妖物（含守关 BOSS/巡场妖王）与未捡掉落原样收起、出来放回（`_leave_world`/`_return_world`），不再靠进门清怪白吞守关 BOSS。参数在 `dungeon.json → farms`。
- **铜钱/经验的出口**：游商常驻「灯油淬火」，每次伤害 +6%、生命上限 +5，价格 150 起每次 +100，买了不下架。以前一局结束会剩 2.4 万铜钱没处花。武器和被动全满后，三选一先出两张可无限叠加的「突破」卡：灯魂淬炼伤害 +4%、命火长明生命上限 +12，以前只剩回血/魂火/铜钱补给。
- **终局 Boss 强化**：完整和疾速模式下灯骸老祖固定 **1,000,000** 血，血条显示千分位数字。新增两招：
  - 「半壁灯海」：700×900 的矩形预警，视口是 1280×720，罩住半个屏幕，玩家离安全边 170 像素；二阶段落下后另一侧立刻补一击，左右连击。
  - 「灯笼坠天」：以玩家为圆心、半径 330 的落点。
  - 血量 20% 以下进入「回光返照」，出招间隔 ×0.7。技能循环见 `enemies.json → boss.cycle`。
- **修掉的不合理处与崩溃**：
  - 网页版疾速/经典模式崩溃：`segments.json` 的 3 段表把 `field` 写成 `"field.jpg"`/`"field2.jpg"`/`"field3.jpg"`，被 `world_view._bg_tex` 再拼 `.jpg` 成 `field3.jpg.jpg` 导致资源加载崩溃。已统一为无后缀键，并在 `selftest.gd` 补全全部段背景资源校验。
  - 秘境/宝库/练级点里倒下，以前按剑冢结算：副本类型没复位，下一次进剑冢会跑错逻辑。现在按失败弹出，扣入场前生命的 30%。
  - 受击清弹时，弹幕遍历越界报 SCRIPT ERROR。
  - 进副本会清掉地上没捡的魂火铜钱与大地图妖物。现在统一收起、出来还原，副本里没捡完的掉落直接入账。
  - 读档后 POI 冷却被存成 true。
  - 秘境顶栏一律显示「剑灵/目标击杀秒数」。现在按副本类型显示，藤妖也有血条。
- **v2.1 实测**：
  - 自检：`selftest.gd` 199 项全部通过（0 失败，含资源校验、练级点/收起还原、淬火/突破、百万血 Boss/半壁灯海/回光返照、存档往返）；`e2e_facing.mjs` 回归通过；`build/web` 总大小 39,991,170 字节（<40MB）。

## 实测结果（终版）
- **平衡**（经典 8 分钟口径，真人代理 σ=0.05）：不进副本 40.7%（3000 局）/ 进 1 次 53.7%（1000 局）/ 进 2 次 55.5%（1000 局），均达标且递增；随机下限 0%；瞄准机器人（60 局）45.0%。**未达标**：飞剑降时进 1 次 −22.0%（目标 25–35%）、进 2 次 −27.8%（达标）；30/10 分钟模式只做了拉伸、未校准（机器人胜率 100%/91.7%）；进 1/2 次档只跑 1000 局。详见 `docs/balance-report.md`。
- **性能**（4× 降速，3 次实测，详见 `PERF.md`）：300 只 59.2–59.5 FPS（p99 16.8–33.3ms，机器有并行负载抖动）、draw_calls **112**（<120 ✅）、贴图 **26.4MB**（<30 ✅）；500 只 51–54 FPS、p99 33.4ms（**未达** <20ms）。构建体积 39,924,290 字节（<40,000,000 ✅）。
- **回归**：`selftest.gd` 133 项通过；`e2e_facing.mjs` 通过；12 步试玩剧本预跑通过。手机横屏 844×390：`docs/verify/phone/` 有标题、开局（摇杆/闪/小地图/葫芦珠）、移动战斗、三选一、暂停 5 张，无裁切；脚本的暂停继续已改用 Esc 键但**未重跑**，手机上的副本/商店/结算/存档仍未验证。
- **与 prototype/index.html 的演进**：原型三屏（标题/对局/结算）→ 成品保持画风与 HUD，新增：双模式标题、大地图+小地图、副本/秘境、铜钱商店、葫芦与小金刚、5 阶飞剑、6 段主题与小 BOSS。
